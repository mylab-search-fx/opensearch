# Лог изменений

Все заметные изменения в этом проекте будут отражаться в этом документе.

Формат лога изменений базируется на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-11-19

### Добавлено

* целевая платформа `.NET 10` и клиент `OpenSearch.Client`
* регистрация одиночного `IOpenSearchClient` через `AddOpenSearch`
* настройка из конфигурации и из кода через `ConfigureOpenSearch`, секция по умолчанию `OpenSearch`
* подключение к одному узлу через `Host`
* статический пул узлов через `HostPool`
* запись ошибки создания клиента в журнал и передача исключения вызывающему коду
* проверка работоспособности `opensearch`: успех, когда доступны все узлы; деградация, когда доступна только часть; неуспешный результат, когда не доступен ни один узел
